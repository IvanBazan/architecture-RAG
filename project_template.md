2. Реализация Post-проверки.

Теперь попробуем доработать модуль RAG с few_shot, который тоже выдавал пароль при запросе.

Мне необходимо для RetrievalQA реализовать свой retriever вместо ипользованного ранее стандартного as_retriever из Chroma

Мой ретривер будет унаследован от BaseRetriever класса.
Реализуем в нем согласно документации методы get_relevant_documents и асинхронный aget_relevant_documents.
В методе get_relevant_documents, который впоследствии будет использоваться методом Invoke, фильтруем чанки по набору слов с регулярными выражениями

```python
def is_malicious_content(text: str) -> bool:
    if not text:
        return False
        
    malicious_patterns = [
        r'ignore\s+all\s+instructions',
        r'output\s*:',
        r'ignore\s+the\s+above',
        r'disregard\s+previous',
        r'you\s+must\s+output',
        r'суперпароль',
        r'пароль\s*:\s*\S+',
        r'password\s*:\s*\S+',
    ]
    
    text_lower = text.lower()
    for pattern in malicious_patterns:
        if re.search(pattern, text_lower):
            return True
    return False
    

class SafeRetriever(BaseRetriever):    
    vectorstore: Chroma = Field()
    k: int = Field(default=3)
    
    class Config:
        arbitrary_types_allowed = True
        
    def get_relevant_documents(self, query: str) -> List[Document]:
        docs = self.vectorstore.similarity_search(query, k=self.k)
        return [doc for doc in docs if not is_malicious_content(doc.page_content)]
    
    async def aget_relevant_documents(self, query: str) -> List[Document]:
        return self.get_relevant_documents(query)
```
